# Traps (one file for each trap)

A trap is a thing that looks right and is wrong. A new trap is a new file in this folder:
`<YYYY-MM-DD>-<short-name>.md`. Two branches that each add a trap then add two files, and
git merges them with no conflict. Do not add a line to one long file.

Form of a file: a title (the trap in one line), then:

- *Trap:* what goes wrong.
- *What to do:* the correct action.
- *Evidence:* a file and a function, or a command.

Use the language standard of the project (`CLAUDE.md`). Correct an old trap in its own
file.
